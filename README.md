# Phil - Wifi controlled stalker bot

Fully open sourced and hobbyist friendly stalker bot that can be controlled from any device connected to the same wifi.
Automatic tracking will be added in the next version of the project!

## Parts Required for the build
- ESP-32 (C3-mini also works)
- 5V3A Power Supply for servos
- 16-Channel Servo Driver
- 6x sg90/mg90
- Bunch of jumper wires

## Print files & specifications
- CAD files - Head, Eyes (yet to be added)
- PLA - eSun Bone White, Elegoo Matte Beige
- Profile - 0.12 Fine @BBL A1M

<sub>You will either need a 3d printer or need to use a printing service for the assembly. Eye mechanism is a modified version of Will Cogley's 3.2 design.</sub>
