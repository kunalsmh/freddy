# Creepy freddy head
![V2](https://img.shields.io/badge/V2-ESP_32-blue)

Freddy head with working animatronic eyes that are controlled via wifi using an esp32. The optional joystick functionality still exists if you'd like to use it.
This is the second version of this project, move over to `V1` for the older version.

Feel free to use this version if you want to!

### Parts Required 
- ESP-32
- 5V3A Power Supply for servos
- 16-Channel Servo Driver
- 6x sg90/mg90
- Bunch of jumper wires

#### You will either need a 3d printer or need to use a printing service for the assembly.

### Print files & specifications
- CAD files - Head, Eyes (yet to be added)
- PLA - eSun Bone White, Elegoo Matte Beige
- Profile - 0.12 Fine @BBL A1M
